# Datenquellen und Lizenzen

Die Dateien in diesem Ordner werden automatisch von der Pipeline erzeugt. Sie stammen aus folgenden Quellen:

| Datei | Quelle | Bedingungen |
|---|---|---|
| `raw/coinmetrics.json` | [Coin Metrics](https://coinmetrics.io) Community Data | [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/): nicht-kommerziell, mit Quellenangabe |
| `raw/fng.json` | [alternative.me](https://alternative.me/crypto/fear-and-greed-index/) Fear & Greed Index | frei mit Quellenangabe |
| `raw/wiki_en.json`, `raw/wiki_de.json` | [Wikimedia Foundation](https://wikimedia.org/api/rest_v1/) Pageviews | offene Daten |
| `raw/price_bitstamp.json` | [Bitstamp](https://www.bitstamp.net/api/) öffentliche API | öffentliche Marktdaten |
| `raw/price_coinbase.json` | [Coinbase Exchange](https://docs.cdp.coinbase.com/exchange/) öffentliche API | öffentliche Marktdaten |
| `raw/funding_deribit.json` | [Deribit](https://docs.deribit.com/) öffentliche API | öffentliche Marktdaten |
| `raw/network.json` | [mempool.space](https://mempool.space/docs/api) | öffentliche API |
| `weekly.json`, `latest.json` | eigene Berechnungen aus den obigen Quellen | wie oben, nicht-kommerziell |

Dieses Projekt ist privat und nicht-kommerziell. Keine Anlageberatung.
